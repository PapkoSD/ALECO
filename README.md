# ALECO: open map of local food in Slovakia

A free, open-source map of farms, salaše, bakeries, milk vending machines, markets, wineries and certified organic producers across Slovakia. No ads, no commission, no cookies: buyers contact producers directly.

**Live: <https://papkosd.github.io/ALECO/>**

- `site/`: the website (plain HTML/CSS/JS, MapLibre + OpenFreeMap tiles, no build step). Deploy the folder as-is to GitHub Pages or Cloudflare Pages.
- `site/data/places.geojson`, `site/data/places.csv`: the public data, generated by the scripts below. The `buy` field lists what you can buy there as product groups (`mlieko`, `syr`, `vajcia`, `maso`, `med`, `ovocie`, `zelenina`, `pecivo`, `vino`; `;`-separated in the CSV). `build_seed.py` derives it from the place type (a bakery sells bread, a salaš cheese), the product list, the type label and the hand-check note. Places that do not say what they sell (most markets and farm shops) have no `buy`.
- `site/data/obce.json`: all ~2,900 municipalities with their centre, so the search box can find any village or town, also one with nothing on the map. Loaded only when someone uses the search.
- `site/data/kraje.geojson`: region outlines. Still generated, but the page no longer loads them since the location search replaced the region filter.
- `site/fonts/`, `site/vendor/maplibre-gl-4.7.1/`: fonts and the map library, served from the site itself so visitors' browsers only contact OpenFreeMap (for map tiles) and GoatCounter (anonymous visit counts, see below). MapLibre came from the npm package, checked against its published sha512.
- `scripts/`: the data pipeline. See `DATA_INVENTORY.md` for sources and `PLAN.md` for decisions.

## What is on the map

| Source | What we take | Notes |
|---|---|---|
| OpenStreetMap (Geofabrik extract) | Farm shops, salaše, wineries, beekeepers, milk/egg vending machines, markets, bakeries, organic and cheese shops | Chains, supermarkets and generic butchers/greengrocers are left out |
| EU organic certificates (TRACES) | Certified producers whose certificate lists food for people, with their products | The certificate PDF gives the product list and, for some control bodies, the farm address |
| GeoNames | Village and postcode coordinates for offline geocoding | Street addresses go to Nominatim (1 request/s, cached) |

Every place gets its kraj, okres and obec from OSM boundary polygons, offline.

## How people search

1. **Kde hľadáte?** Type a village or town and pick it (or press Enter), or press *Moja poloha*. The list then shows the places within 10, 25 (default) or 50 km, nearest first, with a dashed circle on the map; *celé Slovensko* lists everything by distance. The same box also offers product words ("bryndza" → Syry), a product and a town together ("vajcia v Bratislave", "syr pri Pezinku"; the usual Slovak endings are understood) and places by their own name.
2. **Čo chcete kúpiť?** Product chips with counts for the chosen area, from the `buy` field. Chips with nothing nearby are greyed out. When a product is picked, a note says how many nearby places do not tell us what they sell; they stay under *Všetko*. Each place card shows what it is listed under ("Kúpite tu", or "Vyrábajú" for certified producers not checked yet).

Under *Všetko* around a town, bakeries and plain markets ("Trh Brezno") come after everything else, under the heading "Pekárne a trhy": around Bratislava they are more than half of all places. Without a chosen place, the list follows the map; zoomed out to all of Slovakia it shows verified places and places with contacts first.

**Links.** The address always holds the current search, and *Zdieľať výber* copies it, e.g. `?kde=Pezinok&km=10&co=syr`:
`kde` village or town (plus `okres` when two share the name), `km` 10 / 50 / 0 (25 is left out), `co` a product group from the `buy` field, `bio=1`, `miesto` an open place. The visitor's own position (*Moja poloha*) never goes into a link.

## Visit counts

Anonymous counts go to GoatCounter at <https://aleco-sk.goatcounter.com>: no cookies, no IP addresses stored, and localhost is not counted. Besides page views, the site counts these events (never the visitor's position):

| Event | When |
|---|---|
| `obec/<name>` | a village or town is chosen |
| `produkt/<id>` | a product chip is picked |
| `miesto/<id>` | a place card opens (title = place name) |
| `navigovat`, `zavolat`, `web`, `nahlasit-chybu` | buttons and links on a place card |
| `zdielat-miesto`, `zdielat-vyber` | share buttons |
| `moja-poloha` | the location button was used |
| `odkaz/hladanie`, `odkaz/miesto` | someone arrived through a shared link |
| `napisat-email` | the e-mail button in the add/fix dialog |

## Update the data

```bash
python3 scripts/fetch_sources.py                     # OSM extract for Slovakia (~350 MB) + GeoNames
uv run --no-project --with osmium python scripts/osm_extract.py
python3 scripts/traces_organic.py                    # EU organic certificate list
python3 scripts/traces_details.py --download-only    # certificate PDFs, 1 per second, cached
uv run --no-project --with pypdf python scripts/traces_details.py --parse-only
python3 scripts/rpo_extract.py                       # company register (needs the RPO snapshot in ../gastro-leads/data/raw)
python3 scripts/build_inventory.py                   # merge sources
python3 scripts/build_seed.py                        # map data, private outreach list and report
```

`build_seed.py` writes `data/out/report.md` with counts per region and category and every filtering decision.

## Hand-checking

The curated results live in `data/checks/` and are committed, because they are the most valuable data here.

```bash
python3 scripts/checks.py init            # add new certified places to data/checks/places_checks.csv
python3 scripts/find_websites.py          # look for producers' own websites (review before using)
python3 scripts/check_websites.py         # test every website on the map; dead and parked links are dropped
python3 scripts/checks.py set < x.jsonl   # record decisions: sells / wholesale / closed / duplicate / not_local / unclear
python3 scripts/call_list.py              # who still needs a phone call (private: data/out/call_list.csv)
python3 scripts/build_seed.py             # rebuild the map with everything applied
```

Any place on the map can be checked, OSM shops and markets too: `checks.py set` adds the row when the id is not in the file yet. The product words in `how` ("mlieko, syry, vajcia") also decide what the place is listed under in "Čo chcete kúpiť?". On the map, "sells" adds a "Predaj" line with the date it was verified and an "overené" mark in the list. `wholesale`, `closed`, `duplicate` and `not_local` take the place off the map. OSM places last edited five or more years ago say so in their detail card.

## Publish

GitHub Pages serves the site from the `gh-pages` branch, which holds only the contents of `site/`. Commit on `main`, then:

```bash
sh scripts/deploy.sh
```

The link preview image (`site/og.png`) shows every place as a dot; redraw it after a big data update.

## Run locally

```bash
python3 -m http.server 8823 --directory site
```

## Data rules

- Published: OpenStreetMap places, and certified organic **companies** whose certificate lists food for people.
- Not published: sole traders (GDPR, until they agree), certified farms that only grow crops or raise animals for processors, importers and traders, and producers whose certificate address is an office (a shared address, or a farm registered in Bratislava or Košice city).
- Those go to private files for outreach and checking: `data/out/outreach_slovakia.csv` and `data/out/organic_review.csv`. They must never be committed or published.
- The BIO badge is shown only for a valid EU organic certificate and links to the certificate PDF. The page drops the badge by itself on the day after the certificate's end date. Rebuild the data monthly so renewed certificates come back.
